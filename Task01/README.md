# Структура файлов данных

## ratings.csv

Файл содержит оценки пользователей фильмов.

Поля:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- rating — оценка фильма;
- timestamp — время выставления оценки.

## movies.csv

Файл содержит информацию о фильмах.

Поля:
- movieId — идентификатор фильма;
- title — название фильма;
- genres — жанры фильма.

## tags.csv

Файл содержит пользовательские метки для фильмов.

Поля:
- userId — идентификатор пользователя;
- movieId — идентификатор фильма;
- tag — метка;
- timestamp — время создания метки.

## users.txt

Файл содержит информацию о пользователях.

Поля:
- идентификатор пользователя;
- имя пользователя;
- адрес электронной почты;
- пол;
- дата;
- профессия.

Разделитель полей — символ `|`.

## genres.txt

Файл содержит список жанров фильмов. Каждый жанр записан в отдельной строке.

## occupation.txt

Файл содержит список профессий. Каждая профессия записана в отдельной строке.

## ratings_count.txt

Файл содержит минимальный и максимальный идентификаторы пользователей из `ratings.csv` и количество записей для каждого из них.

## sqlite.txt

Файл содержит версию установленной СУБД SQLite и список доступных режимов вывода данных консольной утилиты `sqlite3`.
